# Control de Permitidos · versión 2

Entregas de mercancía a locales en centros comerciales, cobros, devoluciones, inventario e informes.
Usa la misma base de datos de Supabase que Inventario Tienda. El panel de administración es uno solo:
https://franciscoortiz012345-lang.github.io/inventario-tienda/admin.html

## Publicar en GitHub Pages
1. Repositorio `control-permitidos` → Add file → Upload files → sube todo el contenido de esta carpeta (reemplaza lo anterior).
2. Si existe el archivo `estilos.css` de la versión 1, bórralo (ya no se usa).
3. Settings → Pages → rama `main`, carpeta `/ (root)`.

## Archivos
- `index.html`, `app.js`, `config.js`, `permitidos.css`: la aplicación.
- `admin.html`: lleva al panel de administración único.
- `supabase/`: respaldo del esquema (ya aplicado en tu proyecto).
